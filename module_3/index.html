Graduate Applicant Analysis

This web application performs an analysis of Grad Café graduate school applicant data retrieved dynamically from PostgreSQL. "Pull Data" checks Grad Café for newly submitted application results and adds new records to the database (depending on the amount of new data available, this may take some time). "Update Analysis" refreshes the answers on this page using the current contents of the database.
